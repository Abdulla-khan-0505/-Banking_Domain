# 🏦 Banking Domain Data Analytics Project

## 📊 Project Overview

This project presents an end-to-end data analysis of a Banking Domain dataset using Python, SQL, and Power BI. The objective was to analyze customer behavior, loan performance, credit risk, and business KPIs to generate actionable insights for better decision-making.

The project covers the complete data analytics workflow, including data cleaning, exploratory data analysis (EDA), SQL querying, and interactive dashboard development.
